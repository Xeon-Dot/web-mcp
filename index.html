Protocol

Built on MCP Standard

Model Context Protocol의 모든 기능을 그대로 지원하면서 확장합니다.

✅ Full MCP Compatibility

Xeon MCP는 Anthropic이 정의한 Model Context Protocol을 완전히 구현합니다. 모든 MCP 클라이언트와 호환되며, 추가 확장 기능을 제공합니다.

  • Resources — 파일, API, 데이터베이스 등 외부 데이터를 컨텍스트로 제공
  • Tools — AI 에이전트가 실행할 수 있는 함수와 API 정의
  • Prompts — 재사용 가능한 프롬프트 템플릿 관리
  • Sampling — 서버가 클라이언트에 추가 LLM 생성을 요청
  • Transports — stdio, SSE, WebSocket 전송 방식 지원

How It Works

Connect in 3 Steps

Xeon MCP를 시작하는 방법은 간단합니다.

1

계정 생성 및 프로젝트 설정

Xeon MCP에 가입하고 프로젝트를 생성하면 고유한 API 엔드포인트와 API 키가 발급됩니다. 5분이면 완료됩니다.

2

MCP 서버 연결 또는 생성

내장된 30여 개의 MCP 서버 중에서 선택하거나, SDK를 사용해 커스텀 MCP 서버를 작성하고 등록하세요. 모든 서버는 자동으로 검색 가능합니다.

3

AI 에이전트와 연결

Claude Desktop, Cursor, VS Code 등 MCP를 지원하는 모든 클라이언트에서 Xeon 게이트웨이를 통해 서버에 접근하세요. 설정은 단 한 줄이면 됩니다.
