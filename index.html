여러 HTTP MCP를
무료로 사용하는 플랫폼

Xeon MCP는 AI 에이전트와 MCP 클라이언트를 위한 무료 HTTP MCP 허브입니다. 설치나 별도 설정 없이 URL만 복사해 원하는 클라이언트에 붙여넣으면 바로 사용할 수 있습니다.

https://mcp.xeon.kr/searxng
// features

바로 쓸 수 있는 무료 MCP 허브

01

완전 무료

모든 HTTP MCP 서버를 비용 없이 사용할 수 있습니다. 요금제나 가입 절차 없이 바로 연결하세요.

02

설치 없이 URL만

HTTP 방식이라 별도 런타임이나 빌드가 필요하지 않습니다. URL을 복사해 클라이언트에 붙여넣으면 끝입니다.

03

어느 클라이언트와든

Claude Desktop, Cursor, OpenCode 등 표준 MCP를 지원하는 모든 클라이언트에서 동일하게 동작합니다.

04

계속 늘어나는 서버

새로운 MCP 서버가 지속적으로 추가됩니다. 지금은 SearXNG 웹 검색을 시작으로 준비 중인 서버가 많습니다.
