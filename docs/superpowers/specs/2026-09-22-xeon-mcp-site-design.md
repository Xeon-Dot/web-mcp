# Xeon MCP 소개 사이트 설계

날짜: 2026-09-22
상태: 승인됨 (채팅 설계 기준)

## 목적 및 의도

**무엇을:** Xeon MCP를 소개하는 단일 페이지 정적 사이트를 새로 작성한다.

**왜:** Xeon MCP는 여러 HTTP MCP 서버를 무료로 사용할 수 있는 플랫폼이다. 잠재 사용자(개발자)가 플랫폼의 존재와 가치를 이해하고, 지금 당장 연결해 볼 수 있어야 한다.

**누가:** MCP를 아는 개발자 — Claude Desktop, Cursor 등 MCP 클라이언트 사용자.

**성공 기준:**
- 방문자가 "무료 HTTP MCP 플랫폼"이라는 포지셔닝을 히어로에서 즉시 이해한다.
- SearXNG 서버 URL(`https://mcp.xeon.kr/searxng`)을 원클릭으로 복사할 수 있다.
- 데스크톱·모바일 어디서든 깔끔하게 보인다.

## 확정된 요구사항 (사용자 발언)

- 기존 git 이력의 `index.html`(708줄 다크 랜딩)은 재활용하지 않고 **처음부터 새로 작성**한다.
- 포지셔닝은 "고성능 게이트웨이"가 아니라 **"여러 HTTP MCP를 무료로 사용하는 플랫폼"**.
- 서버 목록은 **현재 SearXNG 하나만 실표시**하고, Coming Soon으로 확장 가능성을 나타낸다.
- 섹션: **Hero / 특징·강점 / 서버 목록 / Footer**. (연결 방법 가이드 섹션은 선택하지 않음.)
- 기술 스택: **단일 HTML 파일** (빌드 도구 없음).
- 디자인 무드: **opencode.ai 참고**.

## 가정 (확인 필요 시 수정)

- Xeon 브랜드 컬러가 미정이므로 중성 뉴트럴 팔레트 + 포인트 1색을 사용한다.
- 서버 목록은 현재 1개이므로 JS 레지스트리 없이 HTML에 직접 하드코딩한다 (YAGNI).
- Google Fonts(IBMPlexSans, IBMPlexMono) 로드는 허용된다 (인터넷 연결 환경 기준 배포).
- 별도 백엔드/상태 API는 없다. 완전한 정적 페이지.

## 접근안 선택

- **A안 (채택):** opencode.ai 스타일 재현 — IBM Plex 폰트, 중성 뉴트럴 팔레트, 얇은 보더 섹션 구분, 라이트/다크 자동 전환, 모노스페이스 중심 개발자 톤.
- B안 (기각): opencode 구조 + 인디고/시안 브랜드 컬러 — 참고 무드에서 벗어나고 브랜드 컬러 미정.
- 기존 다크 테크 스타일 재활용 (기각 — 사용자가 "새로 만들기" 선택).

## 섹션 구성 (컴포넌트)

1. **Nav (sticky)** — 로고 "Xeon MCP" + CTA 버튼(서버 목록으로 앵커). 스크롤 시 배경+보더 하단 표시. 모바일: 햄버거 메뉴.
2. **Hero** — 헤드라인 "무료 HTTP MCP 플랫폼" + 설명 문구 + CTA 버튼 + SearXNG URL 모노스페이스 블록(클릭 복사).
3. **특징 (3~4 카드)** — 완전 무료 / HTTP 방식이라 설치·설정 최소화 / 어떤 MCP 클라이언트와도 연결 / 서버 지속 추가.
4. **서버 목록** — SearXNG 카드(이름, 한 줄 설명, URL + 복사 버튼) + Coming Soon 플레이스홀더 카드 1~2개.
5. **Footer** — 링크, 라이선스, "Built on the Model Context Protocol by Anthropic".

## 디자인 시스템 (opencode.ai 준수)

- **폰트:** IBM Plex Sans (본문/헤드라인), IBM Plex Mono (URL, 라벨, 코드).
- **팔레트:** hsl 기반 중성 뉴트럴. 라이트/다크 모두 `prefers-color-scheme: dark` 자동 전환.
  - 라이트: 배경 `hsl(0,20%,99%)`, 약한 배경 `hsl(0,8%,97%)`, 텍스트 `hsl(0,1%,39%)`, 강한 텍스트 `hsl(0,5%,12%)`, 보더 `hsl(30,2%,81%)`.
  - 다크: 배경 `hsl(0,9%,7%)`, 약한 배경 `hsl(0,6%,10%)`, 텍스트 `hsl(0,4%,71%)`, 강한 텍스트 `hsl(0,15%,94%)`, 보더 `hsl(0,3%,28%)`.
  - 포인트(인터랙티브): 옐로우 `hsl(62,84%,88%)` 계열 — CTA 강조 최소 사용.
- **레이아웃:** 중앙 컨테이너 `max-width: 67.5rem`, 섹션은 `border-top: 1px solid` 얇은 보더로 구분, 넉넉한 수직 패딩.
- **버튼:** 사각(4px 라운드), 강한 배경 + 반전 텍스트. 호버 시 약간 밝아짐.
- **본문 행간:** 180~200%.

## 인터랙션 (JS, 최소)

1. **URL 복사** — `navigator.clipboard.writeText` + 복사됨 피드백(아이콘/텍스트 전환, 2초 복귀). 클립보드 API 실패 시(비보안 컨텍스트) 텍스트 선택 fallback.
2. **Nav 스크롤** — 스크롤 위치에 따라 `scrolled` 클래스 토글.
3. **모바일 메뉴** — 햄버거 토글.
4. 스무스 스크롤 앵커 (`html { scroll-behavior: smooth }`).

## 오류 처리

- 클립보드 복사 실패 → 텍스트 자동 선택 + "Ctrl+C로 복사" 안내 노출.
- 그 외: 정적 페이지이므로 네트워크 오류 처리 대상 없음. Google Fonts 로드 실패 시 시스템 폰트 fallback 선언.

## 테스트 / 검증

- 자동 테스트 없음 (단일 정적 HTML — YAGNI).
- 수동 검증:
  1. `python3 -m http.server 8080`으로 로컬 서빙.
  2. 브라우저에서 확인 — 데스크톱/모바일 폭, 라이트/다크 모드 전환.
  3. URL 복사 버튼 동작 (클립보드 내용 확인).
  4. 앵커 내비게이션·햄버거 메뉴 동작.
- HTML 유효성: 브라우저 콘솔 에러 없음 확인.

## 범위 밖 (YAGNI)

- 연결 방법 가이드 섹션, 다중 페이지, JS 서버 레지스트리, 실시간 서버 상태 확인, i18n, 빌드 도구.
